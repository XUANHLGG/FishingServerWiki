## 安装后设置

1. 进入游戏后按V开启选单
2. 第一次开启通常会有教学，可自由选择跳过
3. 通常这样就可以用了

---

## 点歌

### 搜索
```
/zm search [163/kugou/qq/kuwo] [歌手名或歌名]
```

### 播放
```
/zm play [163/kugou/qq/kuwo] [歌手名或歌名]
```

---

## 视频播放器 (需要mod，可进群下载)

在播放区输入 `/vlc play <url>`

---

## 自定义唱片

### 上传

1. 手持任意唱片
2. 输入 `/vj url upload`
3. 开启链接并上传音频
4. 完成上传后可以使用唱片机播放

### 使用已上传音频

1. 手持唱片输入 `/vj url uploads`
2. 选择想使用的音频并点击 `[使用]`
3. 完成后可以使用唱片机播放
